# SketchGyrate

Enables Real-time Vector Graphics Rendering and Animation through advanced Graph-based Core and distributed Server architecture.

SketchGyrate is built to be simple and practical, focusing on doing one thing well.

**Why SketchGyrate?**

- and Animation through advanced Graph-based
- Core and distributed Server architecture

- php
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/SketchGyrate.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

SketchGyrate is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
